## Development

Firmware is initially developed using Arduino IDE and the Arduino-ESP32 core. Source code is version-controlled in Git and hosted on GitHub.

Initial development will use .ino Arduino sketches. As the firmware becomes more complex, reusable functionality may be separated into .cpp/.h modules.

## Disclaimer
All firmware is AI generated or mostly AI generated with my modifications. As an electrical engineer, my 
focus is understanding the hardware and block diagram and not highlighting or claiming any ability to 
generate the code completely from scratch (for efficiency and for hardware focus, which is the highlight 
of this project).
